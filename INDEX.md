## 🎓 Apprentissage progressif

### Niveau 1: Débutant

1. Lire [QUICKSTART.md](QUICKSTART.md)
2. Installer Java et Maven
3. Exécuter `mvn exec:java '-Dexec.mainClass=net.tcgdex.App'` (PowerShell Windows)
4. Voir le résultat

### Niveau 2: Utilisateur

1. Lire [README.md](README.md)
2. Créer votre propre classe selon les exemples
3. Compiler et exécuter
4. Tester différentes recherches

### Niveau 3: Développeur

1. Lire [PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md)
2. Étudier le code source
3. Écrire des tests unitaires
4. Ajouter une fonctionnalité
